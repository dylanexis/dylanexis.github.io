Firefighter Mesh Tracking System in progress

Embedded systems & networking · EECS 473

An offline communication system that tracks firefighter locations and emergency status on scene, without relying on cellular coverage.

  • Designing an offline mapping interface that displays node locations, battery levels, and link status.
  • Integrating with TAK-compatible services and deploying the backend server infrastructure with Docker.

TrashAI - Autonomous Trash-Collecting Rover

Embedded systems & computer vision · EECS 373

An autonomous rover that uses computer vision to find and identify waste, then drives to collect it. I worked across both the vision system and the onboard firmware.

  • Built an OpenCV pipeline to detect and classify waste for autonomous pickup.
  • Wrote embedded C firmware for an STM32 Nucleo to drive motors and servos and read onboard sensors.
  • Implemented UART communication between the STM32 and an NVIDIA Jetson to coordinate vision and motion.
  • Added proximity sensing and communication safeguards for reliable operation.
  • C
  • STM32
  • Python
  • OpenCV
  • NVIDIA Jetson
  • UART
